ຫຼັກການເຮັດວຽກຂອງ Pure CSS Checkbox Hack:

1. ໃຊ້ <input type="checkbox"> ທີ່ຖືກເຊື່ອງໄວ້ດ້ວຍ opacity: 0.

2. ປຸ່ມກົດແມ່ນ <label for="..."> ເຊິ່ງເມື່ອກົດແລ້ວຈະ toggle ສະຖານະ checked ຂອງ checkbox ໂດຍອັດຕະໂນມັດ.

3. ໃຊ້ CSS selector :checked ~ .pure-css-content ເພື່ອຂະຫຍາຍ max-height ແລະ ເຊື່ອງ Gradient Fade.
